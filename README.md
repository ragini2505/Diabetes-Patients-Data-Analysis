# Diabetes Data Analysis

> Exploratory data analysis of diabetes progression using Python, statistical analysis, and visual storytelling.

## Overview

A compact **EDA pipeline** built around a clinical diabetes dataset to explore relationships between patient attributes and disease progression.

The project combines **Pandas + NumPy + Matplotlib + Seaborn** for data inspection, statistical exploration, correlation analysis, and visualization.

## Tech Stack

`Python` · `Pandas` · `NumPy` · `Matplotlib` · `Seaborn` · `Jupyter Notebook`

## Analysis

- Dataset loading & preprocessing
- Descriptive statistical analysis
- Feature correlation analysis
- BMI vs. disease progression analysis
- Distribution & box-plot analysis
- Correlation heatmap visualization
